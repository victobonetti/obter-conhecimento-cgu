# Ouvidoria Digital

Projeto de estudo para a prova **CGU 2026 · AFFC · TI – Desenvolvimento de Sistemas** (Cebraspe, 13/12/2026). É um sistema de ouvidoria em Spring Boot + Vue 3, construído à mão em 8 missões. Cada missão cobre itens do edital e vem um dia antes da teoria correspondente.

## O que tem aqui

| Arquivo | Para quê |
|---|---|
| `docs/ESPECIFICACAO.md` | domínio, requisitos, arquitetura, calendário e as 8 missões (núcleo, extensão, bugs didáticos, pegadinhas, critério de pronto, esqueleto de Q2) |
| `docs/COBERTURA-EDITAL.md` | os 205 itens do edital, com texto literal, e onde cada um é trabalhado (missão ou dia de teoria) |
| `CLAUDE.md` | regras para o Claude Code agir como tutor, não como desenvolvedor |
| `.claude/skills/tutor-de-codigo/SKILL.md` | a skill do tutor (cópia local, carregada pelo Claude Code neste repositório) |

## Começar hoje (M1)

1. Coloque esta pasta onde vai ficar o projeto e rode `git init`.
2. Abra o Claude Code dentro dela.
3. Diga: **"Vamos começar a M1."**
4. Ao fim, preencha `docs/diario.md` (modelo na seção 10 da especificação).

Calendário: M1 hoje (24/11) → teoria de Spring amanhã junto com a M2 → … → M8 em 03/12 → teoria de qualidade e entrega em 04/12. Detalhes na seção 2 da especificação.
